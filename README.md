# Advent 26 · QR-календарь для Алёны

Сайт на GitHub Pages: **24 независимых URL с непрозрачными идентификаторами**, проверочные иллюстрации с датами и редактируемое содержание. Календарь физически переезжает в Берлин после 12–13 декабря.

## Публикация (обязательно сделать в интерфейсе GitHub)

1. Открой [Settings → Pages](https://github.com/davinel000/advent26/settings/pages).
2. Source: **Deploy from a branch**.
3. Branch: **main**, folder: **/docs** → **Save**.
4. Дождись публикации, проверь главную страницу по указанному GitHub адресу. Типичный адрес: https://davinel000.github.io/advent26/
5. Проверь QR-адрес первого и последнего дня на телефоне. Только затем печатай.

> Файлы в репозитории уже подготовлены, но наличие файла в `docs/` само по себе **не подтверждает** успешный деплой GitHub Pages.

## Ссылки по дням

Все 24 адреса сохранены в Google Sheet «Адвент для Алёны — 24 дня и новогодний финал», вкладка **«24 QR · адреса и проверка»**, и в CSV внутри архива `advent26_qr_24.zip`.

Пример формата: `https://davinel000.github.io/advent26/?k=<непрозрачный-ключ>`. Адреса **не содержат даты**, печатать их нужно только из готового списка — не выдумывая значения.

## Где QR-коды

В Google Drive → ChatGPT → **Advent26 — QR и ссылки** лежат:
- `advent26_qr_24.zip` — папки с 24 PNG и 24 SVG;
- `advent26_urls.csv` — соответствие дня и адреса.

Страница для печати на A4 после включения Pages: https://davinel000.github.io/advent26/print.html (24 кода, квадрат 30 мм). QR на бумаге могут потребовать сгибания — проверь реальные внутренние размеры ящичков и сканирование после печати.

## Как менять контент удалённо

Открой [docs/messages.json](docs/messages.json) в GitHub → Edit → измени объект `"01"`, `"02"` и т.д. → Commit.

- `ready: false` — иллюстрация с датой и проверочный текст без спойлеров;
- `ready: true` — иллюстрация с датой + персональный заголовок и текст;
- `title`, `body`, `hint` — редактируемые строки;
- `mediaUrl` — полная публичная HTTPS-ссылка на медиа или страницу (ссылка открывается кнопкой, известные расширения изображений/аудио/видео встраиваются).

Редактировать можно удалённо через телефон. Менять URL или QR после публикации **не нужно**, пока сохраняется проектный домен GitHub Pages.

## Как задуман календарь

- 1–12 декабря: ежедневно конфета + QR, среди них 8 поисков уже напечатанных ч/б фотографий и 4 цифровых сюрприза.
- 13–24 декабря: календарь переезжает вместе с вами; конфеты, маленькие предметы и цифровые истории.
- 31 декабря: самостоятельный новогодний подарок, потенциально совместный культурный опыт в Берлине / Бремене / Гамбурге / Ганновере.
- Ежегодный анализ слов и стикеров Telegram — отдельная традиция, которую лучше подготовить ближе к концу года.

## Приватность

**Это публичный репозиторий и публичный сайт.** QR-адреса трудно угадать по памяти, но все токены можно прочитать в исходном коде, а будущие сообщения будут видны в `messages.json`, даже если `ready: false`. `robots.txt` и `noindex` не защищают секреты. Не записывай настоящие тайники, личную переписку, адрес квартиры или закрытые фотографии в публичный репозиторий заранее. Для действительно секретных сообщений нужен сервер с контролем доступа или отдельное хранилище с приватными данными.
