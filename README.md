# Advent 26

Небольшой сайт с **постоянными адресами для QR**, содержимое которых можно менять из любого города. Исходники хранятся в **приватном репозитории**; публичная страница будет доступна только после отдельной публикации на хостинге.

## Перед печатью QR — важно

1. Подключить этот приватный репозиторий к Cloudflare Pages через **Git integration**.
2. Выбрать Production branch: `main`, Framework preset: `None`, Build command: пусто, Build output directory: `public`.
3. Дождаться успешного деплоя, открыть фактически выданный адрес `https://<project>.pages.dev/`.
4. Проверить страницу `?day=01` на телефоне. Пока `ready` не выставлен в `true`, показывается нейтральная заглушка.
5. **Только теперь** напечатать QR, у каждого полный URL вида `https://<actual>.pages.dev/?day=01`, ... `?day=12`.

Не печатайте придуманный адрес: у Cloudflare фактический домен может отличаться от предполагаемого.

## Как менять содержимое из Берлина

В GitHub открыть `public/messages.json` → Edit this file → изменить записи нужного дня → Commit changes. Обновление автоматически публикуется через Cloudflare Pages.

- `ready: false` — пока показывать заглушку; `ready: true` — открыть послание.
- `title` — заголовок, `body` — основной текст, `hint` — дополнительная строка.
- `mediaUrl` — **только публичная HTTPS-ссылка** на изображение, аудио, видео или любую страницу. Для mp3/mp4/png/jpg компонент встроит медиа. Для других ссылок создаст кнопку.
- `kind: "hunt"` — фото спрятано дома; `digital` — ссылка или сообщение. Это поле нужно для планирования и не влияет на дизайн.

Сейчас в списке 1–12 декабря предусмотрены **8 поисков фотографий и 4 цифровых сюрприза**. Дни 13–24 добавлены как запасные слоты на случай продолжения в Берлине. До выбора реального места тайника подсказки не нужно делать публичными.

## Приватность и сюрпризы

Приватность GitHub-репозитория **не делает опубликованную страницу закрытой**. Любой человек с публичной ссылкой может посмотреть опубликованные тексты и изображения. Не добавляйте личные переписки, закрытые альбомы, ключи и адреса. Метатег noindex препятствует обычному индексированию, но **не защищает доступ**. Записи в `messages.json` доступны технически любому посетителю сайта, даже если `ready: false`; настоящие секреты публикуйте только в день открытия.

## Размер печати

Не уменьшать QR до нечитаемого размера: на бумаге выделить около **23–25 мм под весь квадрат** с белыми полями; проверить пробную печать на телефоне. При 24–25 мм внутри ящичка 30 мм может остаться недостаточно места под конфету — можно сворачивать карточку, а сам QR печатать 25–27 мм на тонкой бумаге.

## После 13 декабря

Календарь может поехать вместе с вами в Берлин. Не оставляй подсказки на физические тайники в Бремене после выезда. Финал 31 декабря — отдельный подарок и/или совместный вечер, не обязателен для работы сайта.

## Печать из браузера

После подключения Cloudflare Pages открой `<реальный URL сайта>/print.html`: страница автоматически создаст 12 QR-кодов, ориентируясь на фактический опубликованный домен. Распечатать на A4 в масштабе 100%, проверить первый и последний QR перед вырезанием. Генератор использует внешнюю JS-библиотеку с cdnjs — страница печати требует интернета при загрузке.
